# Bhushan Ramesh Chaudhari — Professional Portfolio

A responsive, single-page portfolio built with HTML and CSS. No build tools or frameworks are required.

## Files
- `index.html` — portfolio page
- `profile-photo.jpeg` — profile image
- `resume.pdf` — resume download
- `CNAME` — optional custom domain configuration

## Publish with GitHub Pages
1. Create a public repository named `Bhushan-rc.github.io` under the GitHub account `Bhushan-rc`.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. The site should become available at `https://bhushan-rc.github.io/` after GitHub Pages finishes deploying.

## Custom domain
Only keep the included `CNAME` file if you control the DNS for `profile.app` or its administrator has authorized the subdomain. In GitHub Pages settings, set the custom domain to `bhushan-rc.profile.app` and configure the DNS CNAME record for host `bhushan-rc` to point to `Bhushan-rc.github.io`. DNS setup is managed by the domain owner and may take time to propagate.
